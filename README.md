# ORBIT — نسخه آماده GitHub Pages

این پوشه را بدون تغییر ساختار داخل یک مخزن GitHub قرار بده. فایل `index.html` باید در ریشه مخزن باقی بماند.

## انتشار

1. یک Repository جدید در GitHub بساز.
2. تمام فایل‌ها و پوشه `icons` را در ریشه Repository آپلود کن.
3. در Settings وارد Pages شو.
4. در بخش Build and deployment گزینه Deploy from a branch را انتخاب کن.
5. شاخه `main` و پوشه `/root` را انتخاب و ذخیره کن.
6. پس از آماده‌شدن آدرس، آن را در Safari باز کن و Add to Home Screen را بزن.

## نکات مهم

- اطلاعات مالی در IndexedDB همان مرورگر ذخیره می‌شوند و داخل GitHub قرار نمی‌گیرند.
- حذف داده‌های Safari یا حذف وب‌اپ ممکن است اطلاعات را پاک کند؛ مرتب نسخه پشتیبان JSON بگیر.
- برای حفظ اطلاعات، آدرس GitHub Pages و نام مخزن را بعداً تغییر نده.
- پس از اولین بارگذاری موفق، برنامه و پوسته اصلی آن بدون اینترنت نیز باز می‌شوند.
- برای دریافت نسخه جدید پس از هر آپلود، برنامه را یک بار با اینترنت باز کن.

## فایل‌ها

- `index.html`: برنامه اصلی
- `manifest.webmanifest`: مشخصات نصب PWA
- `sw.js`: کش و اجرای آفلاین
- `icons/`: آیکون‌های نصب آیفون و اندروید
